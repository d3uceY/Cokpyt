# Search PyPI

Find any published project and install it without leaving the app.

![The Search page](/img/search.png)

Type a name and press **Enter**. Results are the projects whose names contain what you typed.

Each result shows the name, its summary, the latest version, and an install button. A package already in the active environment is marked **installed**, and its button reads **Reinstall**.

Search always installs the latest version. For a specific one, pin it from [Installed Packages](./installed-packages) (`requests==2.32.0`).
