# Settings

Appearance, updates, the active environment, and the files Cokpyt keeps.

![The Settings page](/img/settings.png)

## Appearance

**Light** or **Dark**. Remembered between runs, and applied before the window paints.

## About

The Cokpyt version and platform. **Check for updates** asks GitHub for the latest release and links to it when one is newer.

## Active environment

Interpreter path, environment root, kind, how it was found, and where Python, pip, and site-packages live. **Open folder** reveals it in your file manager.

## Stored data

Cokpyt keeps a config file, a log, the operation history, and a copy of the PyPI name index. Nothing about your packages is copied anywhere.

- **Refetch the index** — downloads every PyPI project name again. This happens on the first search anyway.
- **View the log** — opens the log in the console panel.
- **Clear the log** — deletes the stored log lines. History is separate.
- **Show the intro again** — restores the first-run note on Overview.
