## What is Cokpyt?

`pip list` shows one interpreter. Cokpyt finds *every* Python environment on your machine — launcher installs, standalone runtimes, venvs, conda — and puts them on one dashboard. Browse packages, search PyPI, and install, upgrade or uninstall with a click. No terminal.

**Cokpyt is the GUI you always wished pip shipped with.**

## Features

- **Environments** — every interpreter and virtual environment on the machine, with its package count
- **Overview** — machine-wide totals and recent activity
- **Installed Packages** — filter, install, upgrade, uninstall, bulk uninstall
- **Updates** — packages that are behind, with the size of the version jump
- **Search** — PyPI search, install straight from the results
- **Doctor** — interpreter, pip, and PyPI checks, with fix hints
- **History** — every install, upgrade, and uninstall, exportable as CSV
- **Cleanup** — measure and remove pip caches, `.egg-info` folders, and `__pycache__`
- **Console** — pip's output, streamed live

Full guides: [docs](https://d3uceY.github.io/Cokpyt/).
